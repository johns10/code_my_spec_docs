# CodeMySpecWeb.AgentConversationLive

Read-only view of a sprite agent's conversation history for one project — the turns it took, the tools it called and what they returned, with sub-agent turns attributed to the sub-agent. Streams new turns in as the agent takes them. Deliberately separate from InboxLive: that is a support queue where a person is writing to you, this is a machine you are watching.

## Type

liveview

## Dependencies

- CodeMySpec.Conversations
