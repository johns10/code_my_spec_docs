# CodeMySpecWeb.CredentialsLive

One-sitting credential intake for every credential the chosen options need. Each is proven with a real provider call before any provisioning begins, and one missing a permission is rejected naming the permission it needs. Credentials Sam must create by hand come with directions — where in the console, and that the secret cannot be read again. Setup refuses to start until every needed credential passes.
