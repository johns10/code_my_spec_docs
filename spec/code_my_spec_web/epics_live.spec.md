# CodeMySpecWeb.EpicsLive

Live context grouping the LiveViews and LiveComponents for the active project's epics. Users browse epics, create and edit them, assign stories, and mark a story or an epic's stories ready for development to control the pace at which work enters the build queue.

## Type

live_context

## Dependencies

- CodeMySpec.Epics
- CodeMySpec.Stories
- CodeMySpec.Users.Scope
