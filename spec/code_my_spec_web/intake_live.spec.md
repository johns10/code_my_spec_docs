# CodeMySpecWeb.IntakeLive

The anonymous intake flow. A visitor describes what they want to build, answers the two shaping questions in operator language, and gets back a plan stating every inference it made — all without signing in. The plan survives leaving and returning in the same browser. Signup turns the confirmed names into an account and project, then hands off to the running workspace and the story interview.
