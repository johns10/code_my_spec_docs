# CodeMySpec.McpServers.Stories.Tools.DeleteStory

MCP tool that permanently deletes a user story from the system. This tool integrates with the Anubis MCP framework to expose story deletion functionality to AI agents like Claude Code.

## Dependencies

- CodeMySpec.Stories
- CodeMySpec.McpServers.Stories.StoriesMapper
- CodeMySpec.McpServers.Validators
- Anubis.Server.Component
- Anubis.Server.Frame
- Anubis.Server.Response
- Ecto.Changeset
