# CodeMySpec.EpicDispatch

The hand-off: an epic the user has agreed to build goes to a working copy, and agents there do the detailed design and the code. Owns the approval gate, the assign-when-idle condition (nothing in progress and unassigned work exists), and the reporting the main agent does about work it is not doing. Separate from Epics, which is the record of what an epic is — this is what happens when one is agreed to.
