# CodeMySpec.Promotion

Getting a working copy's finished work onto the checkout the local application runs, so QA tests the code that was written rather than a stale app. Gates on the copy carrying no problems against a fresh analyzer sweep, refuses a dirty tree, merges to main, restarts the running application, and answers per story whether that story's files are present on the running copy at the content its work produced. Distinct from Deploys, which is the infrastructure path for remote environments and is filtered out when devops is off.
