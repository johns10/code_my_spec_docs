# Faker.Team.En

Functions for generating team related data in English

## name/0

Returns a string of the form [state] [creature]

## Examples

    iex> Faker.Team.En.name()
    "Hawaii cats"
    iex> Faker.Team.En.name()
    "Oklahoma banshees"
    iex> Faker.Team.En.name()
    "Texas elves"
    iex> Faker.Team.En.name()
    "Iowa fishes"
