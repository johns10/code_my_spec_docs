# Faker.Code

Functions for generate common codes.

## isbn10/0

Returns a random isbn10 code

## Examples

    iex> Faker.Code.isbn10
    "015426461X"
    iex> Faker.Code.isbn10
    "0832970522"
    iex> Faker.Code.isbn10
    "3570203034"
    iex> Faker.Code.isbn10
    "2097337600"
