# Faker.Person.Es

Functions for name data in Spanish

## name/0

Returns a complete name (may include a suffix/prefix or both)

## Examples

    iex> Faker.Person.Es.name()
    "Sta. Daniela Agosto MD"
    iex> Faker.Person.Es.name()
    "Alfonso Menéndez"
    iex> Faker.Person.Es.name()
    "Sr. Francisco Jaimes"
    iex> Faker.Person.Es.name()
    "Manuel Lucio MD"
