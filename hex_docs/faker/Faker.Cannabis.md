# Faker.Cannabis

Functions for generating Cannabis related data

## thc/0

Returns a thc percentage for a cannabis thc

## Examples

    iex> Faker.Cannabis.thc()
    "18.1%"
    iex> Faker.Cannabis.thc()
    "30.4%"
    iex> Faker.Cannabis.thc()
    "28.6%"
    iex> Faker.Cannabis.thc()
    "40.6%"
