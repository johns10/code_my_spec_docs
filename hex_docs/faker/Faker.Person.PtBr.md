# Faker.Person.PtBr

Functions for name data in Brazilian Portuguese

## name/0

Returns a complete name (may include a suffix/prefix or both)

## Examples

    iex> Faker.Person.PtBr.name()
    "Sra. Kaique Mendes Neto"
    iex> Faker.Person.PtBr.name()
    "Roberta Garcês"
    iex> Faker.Person.PtBr.name()
    "Sr. Vitor Albuquerque"
    iex> Faker.Person.PtBr.name()
    "Maria Laura da Penha Jr."
