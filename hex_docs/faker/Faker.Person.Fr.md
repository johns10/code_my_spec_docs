# Faker.Person.Fr

Functions for name data in French

## name/0

Returns a complete name (may include a suffix/prefix or both)

## Examples
    iex> Faker.Person.Fr.name()
    "Madame Marcel Duplantier MD"
    iex> Faker.Person.Fr.name()
    "Quentin Garnier"
    iex> Faker.Person.Fr.name()
    "Docteur Camille Fontaine"
    iex> Faker.Person.Fr.name()
    "Serge Bassett V"
